🏗️ Architecture (3 layers)

Layer 1 — Central Management DB
Users, devices, assignments, permissions, connector configs, audit logs.

Layer 2 — Secure Backend (required for production)
API Gateway · Auth · DB Router · Connector Adapters · permission checks.
Service account / private keys never in browser HTML/JS.

Layer 3 — User data databases
Firebase / Supabase / MySQL / PostgreSQL / MongoDB / Custom REST — isolated per user or namespace.
Recommended decisions (doc §12)
• Hybrid: separate DB or shared DB + namespace — Admin chooses
• Assignment: User-based (+ optional device override)
• Admin control: Custom role permissions per admin
